# CO₂ Refrigeration Data Analysis

## Overview

This repository contains Python scripts for analyzing refrigeration system data, specifically focusing on **CO₂-based** refrigeration systems. The code processes time-series data from various sensors, computes thermodynamic properties, and applies polynomial models to evaluate system performance and efficiency.

### Key Features
- **Data Processing:** Cleans and structures CSV datasets using `pandas`.
- **Thermodynamic Calculations:** Computes enthalpy, pressure, and temperature values using `TDN` and `PSI` modules.
- **Polynomial Models:** Implements compressor efficiency estimation using predefined polynomial equations.
- **Moving Average Filtering:** Applies smoothing techniques to enhance data analysis.
- **Time Synchronization:** Adjusts timestamps for consistent comparisons across datasets.
